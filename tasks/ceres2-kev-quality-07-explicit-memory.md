# 07 显式记忆更正、删除与跨对话使用

- 状态：待开始。
- 负责人：Memory唯一实施者，专职Tester验证。
- 所属：[04总TASK](ceres2-local-followup-04-real-evaluation-feedback.md)；[规格](../docs/plans/ceres2-kev-quality-followup-spec.md)。
- 阻塞：[02新环境基线](ceres2-kev-quality-02-baseline-labels.md)。

## 交付

用户在现有聊天中保存、读取、更正和删除自己的记忆，新对话只使用有效偏好，当前显式条件优先；删除后迟到任务或重启不恢复旧内容。

## 验收

- [ ] 实际公共聊天/记忆路径完成CRUD，绑定正确owner、当前记忆标识/版本与明确指令，不把回忆当加购授权。
- [ ] 按现有canonical会话/打开方式验证跨对话，不假设同owner可任意创建新Guide session。
- [ ] 当前条件覆盖历史偏好，域/角色/用户隔离符合已有合同。
- [ ] 删除后的迟到结果、重启和重放不复活，必要修复有公共行为RED/GREEN与适用回归。
- [ ] 真实采样与受控时钟/竞争边界分开，未验证部分留未知，不新建后台或擅自导入旧记忆。

## 证据与下一步

本票可与03/06独立推进，共享入口单一owner。基础记忆及删除保护技术门槛通过后释放08。
