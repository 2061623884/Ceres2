- [ ] 多范围结果保留各自有效引用，早期适用证据不会被“仅最后 ref 有效”淘汰；版本失效、伪造、跨 owner／request 的引用被拒绝，不能捏造全面覆盖。
- [ ] 模型上下文丢失材料时可重新取得已有证据内容而非死指针；返回证据对应真实调用时才使用配对 tool result。
