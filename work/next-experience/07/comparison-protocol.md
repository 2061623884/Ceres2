## Execution and measurement

Sole Tester runs baseline then candidate against fresh equivalent isolated fixtures. Controlled runs establish public contract invariants only. Save complete provider requests, raw responses/SSE, authoritative readbacks, visible turn, model-call starts/completions, provider usage provenance and errors. No real-provider execution without separately available authorized setup. Actual configured provider/model is currently unknown and must remain null, not copied from placeholders.

For a future real comparison freeze exact configured model/provider identifier and sanitized settings, versions, source manifests, order clock and fixture state before execution. Run paired A/B then B/A order for each variant, disclose sample count and cold/warm conditions; preserve failures/cancellations. Human reviewer sees blind full-turn pairs and records better/tie/worse plus cited evidence for result-first, readable Chinese, repetition, relevant necessary next step, factual/status integrity and restrained emoji. Correctness violations block any quality conclusion. No shorter-is-better rule or exact-string naturalness score.

Record call categories separately: Kev, main role, ordinary-claim checks, introduction generation and introduction validation. Tokens are provider-reported input/output/cache counters or null with coverage/provenance. Unknown is never zero. SDK placeholder cost is not measured cost. Character counts use Unicode code points including whitespace, with system/context, connective, host facts and complete visible text separated.

Timing events: client request, first visible status, first useful factual content, authoritative response, card/receipt rendered-and-operable, generation start/end, first validated server publication, first client delta arrival/render, terminal/loading close, full task. Use monotonic spans within one clock domain. Do not subtract cross-machine wall clocks without synchronization. First bytes are not first useful facts, server publication is not client rendering. The30s/15s budgets remain protection ceilings, never promised SLA. Report raw paired values and sample limits before summaries; no speed/cost/language improvement is established by this protocol.
