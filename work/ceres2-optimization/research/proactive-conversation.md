# 可可同一轮主动消息：Pi 接缝与安全边界

调查日期：2026-10-07。本文记录最新用户决策下的技术事实，供根主会话继续定规格。

## 已确认的产品前提

用户已明确：主动性指同一个 Agent、同一个 user turn、同一个 Pi Agent Loop 内可选地产生多条 assistant interim；不要求每轮都发消息，不为生成气泡追加 LLM 调用。工具进度仍是进度状态，不伪装成 assistant 文本。保留 Pi，借鉴 Hermes 的消息分段机制；不引入 heartbeat、跨 turn 续跑、离线/跨渠道提醒。本轮的中间文本与最终业务闭环分开：final JSON、验证器、宿主生成的商品/政策/订单事实仍走现有路径。

## 可行动结论
