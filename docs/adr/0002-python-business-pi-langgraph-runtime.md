# 保留 Python 业务权威，采用 Pi 与 LangGraph 混合运行架构

状态：accepted（2026-10-05 12:42 UTC）；架构方向确认；2026-10-05 15:42 UTC 已另行授权干净重建与持续实施。

Ceres2 保留 Python 的权威业务事实与执行服务，以 Node／TypeScript 中的实际 Pi SDK 运行售前，以 Python LangGraph 运行售后，不在本阶段全量重写为 TypeScript。相比整套语言迁移，这一选择延续已有业务语义与验收边界，业务服务在新工程按票选择性重建，同时实际采用所选 runtime，避免把运行引擎更换扩大为全部业务重写。

代价是跨进程通信、停止／等待／恢复和生命周期管理需要明确契约；具体服务边界、IPC 协议、进程托管和存储适配尚未确定。本决定补充 [ADR 0001](0001-canonical-shopping-authority.md) 中原先开放的语言方向，不改变单一业务事实权威、可信用户身份和业务副作用／回执原子性原则，也不把其待复核的数据库集成方式直接定案。业务范围与最新确认见 [PROJECT](../../PROJECT.md)。
